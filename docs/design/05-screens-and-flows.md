# 5) خريطة الشاشات وتدفق العمل

## 5.1 نظام أكواد الشاشات (زي الأنظمة المؤسسية الكبيرة)

كل شاشة ليها كود ثابت: `<الوحدة><4 أرقام>` — المستخدم يكتبه في صندوق البحث ويفتحها فورًا.

| الرقم الأول | النوع | مثال |
|---|---|---|
| **1xxx** | إعداد وبيانات أساسية | `MDM1010` الأصناف |
| **2xxx** | تشغيل/حركات (بتكتب في الدفتر) | `EXE2010` إطلاق أوامر العمل |
| **3xxx** | استعلام (قراءة فقط) | `EXE3010` استعلام أوامر العمل |
| **4xxx** | تقارير وتحليل | `OEE4010` تقرير OEE |
| **5xxx** | لوحات لحظية | `DSH5010` لوحة الخط |
| **9xxx** | إدارة النظام | `SYS9010` المستخدمين |

الكود ثابت للأبد (حتى لو اسم الشاشة اتغير) — عشان التدريب والدعم الفني و"افتح شاشة EXE3010" في التليفون تفضل صح.

## 5.3 تدفقات العمل الأساسية

### التدفق 1 — تجهيز المصنع (مرة واحدة، يوم التثبيت)
```
معالج التثبيت → SYS9060 الإعدادات/يوم الإنتاج → MDM1010 هيكل المصنع
→ SYS9120 استيراد الأصناف والـBOM من Excel → MDM1050 المسارات
→ MDM1060 الورديات → SYS9040 أسباب التوقف والفاقد → SYS9010/9020 المستخدمين والأدوار
→ SYS9030 تسجيل المحطات والشاشات → LBL1010 الطابعة والملصقات
```
**هدف تجاري:** مصنع بخط واحد يشتغل في **يوم واحد**.

### التدفق 2 — من الأمر للمنتج النهائي (قلب النظام)
```
 المخطط                المشرف               العامل (المحطة)                    الجودة
 ──────                ──────               ──────────────                     ──────
 EXE2010 ينشئ أمر  ─►  EXE2010 يطلقه   ─►   EXE2020: يختار الأمر أو يمسحه
 (أو استيراد ERP)      للخط + وردية         ↓
                       (يطبع ملصقات           امسح الوحدة (Track-In)
                        السيريال/اللوت)      ↓  النظام يتحقق: المسار، الحجز، المؤهل
                                              امسح الخامات (Consume) ← لو الصنف متتبع
                                              ↓
                                              اشتغل … ثم: جيد ✔ / فاقد ✖ (سبب) / إعادة ↺
                                              ↓  (Track-Out)
                                              لو الخطوة فحص → نموذج الفحص ─── فشل ──► Hold تلقائي ─► QMS2020
                                              ↓                                                          إفراج/فاقد/إعادة
                                              الوحدة تنتقل لطابور الخطوة التالية
                                              ↓ … آخر خطوة
                       EXE3010 يتابع ◄──────  Completed → (تعبئة/ملصق نهائي)
                       ويقفل الأمر
```

### التدفق 3 — شاشة المحطة (أهم شاشة في النظام كله)
مصممة لـ**عامل بجوانتي، على شاشة لمس، في دوشة، ومش لازم يقرا كويس**:
```
┌──────────────────────────────────────────────────────────────────┐
│ خط 2 • محطة لحام 3        وردية A     أحمد م. (بادج)      ● متصل │
├──────────────────────────────────────────────────────────────────┤
│ أمر: WO-2026-00123   منتج: غطاء 40L   المطلوب 500  تم 312  ▓▓▓▓░ │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│            [  امسح القطعة أو اللوت  ▌ ]                          │
│                                                                  │
│   آخر مسح:  SN-000451  ✔ خرجت جيد   منذ 5 ثواني                   │
├───────────────┬───────────────┬───────────────┬──────────────────┤
│   ✔ جيد       │   ✖ فاقد       │   ↺ إعادة     │   ⏸ توقف          │
│  (أخضر كبير)  │  (أحمر)        │  (برتقالي)    │  (أصفر)           │
└───────────────┴───────────────┴───────────────┴──────────────────┘
```
- المسح هو الفعل الأساسي؛ الأزرار الكبيرة للي مش بيتمسح.
- **كل رد فعل بلون + صوت + نص كبير**؛ الرفض بيقول السبب بكلمتين ("القطعة محجوزة – كلّم الجودة").
- لو الاتصال بالسيرفر وقع: شريط أحمر ملء العرض "غير متصل – لا تكمل التسجيل"، **مش** تخزين صامت.
  (التخزين المؤقت للأحداث البسيطة زي العدادات مؤجل لـV2 بعد دراسة، لأن فرض المسار محتاج السيرفر.)

### التدفق 4 — التوقف
```
الماكينة وقفت ← (V1) العامل يدوس ⏸ ويختار السبب من أيقونات
               (V2) الـEdge يكتشف الوقوف تلقائيًا → تظهر على المحطة "الماكينة واقفة من 3 دقائق — اختار السبب"
  ↓
توقف مفتوح بيظهر أحمر على لوحة الخط DSH5010 + (V1.5) تصعيد بعد X دقيقة
  ↓
استئناف → يقفل التوقف → OEE يتحدث
  ↓
المشرف في OEE2010 يكمل أي توقفات "بدون سبب" قبل قفل الوردية
```

### التدفق 5 — الجودة: حجز وإفراج
```
مصدر الحجز: فشل فحص (تلقائي) | مشرف/جودة (يدوي) | شكوى عميل (على لوت كامل عبر TRC)
  ↓
Hold على: وحدة | أمر كامل | لوت خامة (ويتنشر تلقائيًا على كل الوحدات اللي استهلكته)
  ↓  (أي محاولة Track-In لوحدة محجوزة بترفض في المحطة)
QMS2020: الجودة تقرر → إفراج (Use-as-is) | إعادة تشغيل | فاقد | إرجاع للمورد
  ↓  توقيع إلكتروني + سبب إلزامي → حركة في الدفتر
```

### التدفق 6 — التتبع والاستدعاء (Recall)
```
شكوى على منتج SN-000451
  → TRC3010 (للخلف): اتعمل في WO-123، وردية B يوم 2026-10-02، عمال X و Y، ماكينة M3،
                      خامات: لوت بلاستيك L-889 من المورد Z، فحص بالمقاس كذا
  → TRC3020 (للأمام) على L-889: استُخدم في 1,240 قطعة في 3 أوامر؛ 800 شحنت، 440 في المخزن
  → Hold جماعي على الـ440 بضغطة + تصدير قائمة الـ800 للعميل
```
**هدف أداء:** إجابة الاستدعاء كاملة في < 5 ثواني.

### التدفق 7 — تسليم الوردية
المشرف يفتح RPT4030 → النظام بيجمع تلقائيًا: الإنتاج مقابل الخطة، الفاقد، التوقفات
(وأي توقف بدون سبب يمنع القفل)، الحجوزات المفتوحة، الملاحظات → توقيع → المشرف
الجاي بيشوفه أول ما يدخل.
