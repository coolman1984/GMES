# 2) خريطة جميع الوظائف

النظام = **نواة (Kernel)** دايمًا موجودة + **وحدات (Modules)** يشتريها العميل حسب احتياجه.
كل وحدة ليها كود من 3 حروف بيظهر في أكواد شاشاتها (زي `EXE` للتنفيذ).

```
                         ┌───────────────────────────────────────────┐
  وحدات اختيارية        │ APS  SPC  CMMS  TOOL  LBR  ALM  EDGE  ERP │   ← تتركب وتتشال
  (Plug-in modules)      │ QMS  TRC  OEE   WIP   RPT  DSH  LBL  ...  │
                         ├───────────────────────────────────────────┤
  النواة (Kernel)        │ SYS: مستخدمين/صلاحيات/تدقيق/تراخيص/إعدادات │   ← دايمًا موجودة
                         │ MDM: مصنع/منتجات/خامات/مسارات/ورديات      │
                         │ EXE: أوامر العمل + دفتر الحركات + المحطات │
                         └───────────────────────────────────────────┘
```

**قاعدة ذهبية:** النواة لوحدها لازم تكون **منتج قابل للبيع** — مصنع صغير يقدر
يشغل أوامر عمل، يمسح باركود في المحطات، ويعرف الإنتاج الجيد والفاقد، من غير أي وحدة.

## 2.1 النواة (Kernel) — دايمًا موجودة

### SYS — النظام والأمان
| الوظيفة | التفاصيل |
|---|---|
| المستخدمين | إنشاء، تعطيل (مش حذف أبدًا)، كلمات سر (argon2)، قفل بعد محاولات فاشلة |
| دخول العامل بالبادج | مسح كارت/باركود العامل + PIN اختياري، على المحطة |
| الأدوار والصلاحيات (RBAC) | صلاحية = (شاشة × فعل: عرض/إضافة/تعديل/حذف/تصدير/اعتماد) + نطاق (مصنع/منطقة/خط) |
| التوقيع الإلكتروني | إعادة إدخال كلمة السر + سبب، للإجراءات الحساسة (إفراج عن حجز، تعديل كمية مسجلة) |
| سجل التدقيق | كل تغيير في البيانات الأساسية: مين، إمتى، قبل/بعد |
| دفتر الحركات غير القابل للتلاعب | سلسلة Hash؛ أداة تحقق تكشف أي تعديل (§4.4) |
| الترخيص | ملف ترخيص موقّع (Ed25519)، بيتفحص offline، بيحدد الوحدات والمصنع وعدد المحطات |
| الإعدادات | لكل مصنع: اللغة، المنطقة الزمنية، بداية يوم الإنتاج، ترقيم المستندات |
| الترقيم | عداد لكل نوع مستند بصيغة قابلة للضبط (`WO-{yyyy}-{seq:5}`) |
| القوائم والرموز (Code tables) | أسباب التوقف، أنواع العيوب، أسباب الفاقد… قوائم قابلة للتعديل بدون برمجة |
| النسخ الاحتياطي والاستعادة | مجدول + يدوي + اختبار استعادة من الشاشة |
| الاستيراد/التصدير | Excel/CSV لكل البيانات الأساسية، بقالب وتحقق قبل الحفظ |
| اللغات | عربي (RTL)، إنجليزي، وإضافة لغة = ملف ترجمة |

### MDM — البيانات الأساسية
| الوظيفة | التفاصيل |
|---|---|
| هيكل المصنع (ISA-95) | Site → Area → Line (Work Center) → Station (Work Unit) → Equipment |
| المنتجات والخامات | Item واحد بنوع (منتج نهائي/نصف مصنع/خامة/مستهلكات)، وحدة قياس، تحويلات وحدات |
| طريقة التتبع لكل صنف | بدون / دفعة (Lot) / رقم تسلسلي (Serial) — قرار لكل صنف |
| قائمة المواد (BOM) | بإصدارات وتاريخ سريان، كمية لكل وحدة، نسبة هالك مسموحة |
| المسار (Routing) | خطوات (Operations) بترتيب، كل خطوة: محطات مسموحة، زمن قياسي، فحص إلزامي؟، خامات تستهلك هنا |
| الورديات والتقويم | نماذج ورديات، أيام عطلات، **يوم الإنتاج** (مثلًا يبدأ 07:00) |
| الأسباب | أسباب التوقف (مخطط/غير مخطط)، الفاقد، إعادة التشغيل، الحجز |

### EXE — التنفيذ الأساسي
| الوظيفة | التفاصيل |
|---|---|
| أوامر العمل (Work Orders) | إنشاء يدوي أو استيراد، حالات: Draft → Released → In-Progress → Completed → Closed (+ On-Hold, Cancelled) |
| الإطلاق للخط | اختيار الخط وتاريخ/وردية الإنتاج |
| وحدة التتبع (Unit) | قطعة بسيريال، أو دفعة/لوت بكمية، أو "حاوية" (صندوق/بالتة) |
| Track-In / Track-Out | دخول وخروج الوحدة من خطوة في محطة، بالمسح |
| تسجيل الكميات | جيد / فاقد (بسبب) / إعادة تشغيل (بسبب) |
| فرض المسار | النظام يرفض تخطي خطوة أو الدخول لمحطة مش في المسار (مع إمكانية استثناء بصلاحية وسبب) |
| التقسيم والدمج | Split/Merge للوت، مع حفظ النسب |
| الإلغاء المنضبط | أي حركة غلط تتصلح بـ**حركة عكسية** (Reversal) مش بتعديل — الدفتر لا يُمحى |
| محطة العامل | شاشة لمس بسيطة: الأمر الحالي، امسح، أدخل كمية، سجل عيب/توقف |

## 2.2 الوحدات (Modules)

| الكود | الوحدة | الوظائف الرئيسية | يعتمد على |
|---|---|---|---|
| **WIP** | المخزون تحت التشغيل | أرصدة كل خطوة/محطة، عمر الـWIP، قوائم انتظار، حاويات، تحويل بين مواقع | Kernel |
| **TRC** | التتبع الكامل (Genealogy) | استهلاك الخامات بالمسح (لوت/سيريال)، شجرة الأب/الابن، تتبع للأمام (المنتج راح فين) وللخلف (اتعمل من إيه)، استدعاء (Recall) | Kernel |
| **QMS** | الجودة | خطط فحص (Inspection Plans) لكل منتج/خطوة، نقاط قياس بحدود، عينة، عيوب بكود وموقع، **حجز/إفراج** (يدوي أو تلقائي عند فشل فحص)، NCR، قرار (Rework / Scrap / Use-as-is / Return) | Kernel |
| **SPC** | التحكم الإحصائي | X̄-R, X̄-S, I-MR, p/np/c/u charts، قواعد Western Electric/Nelson، Cp/Cpk، تنبيه عند خروج القياس | QMS |
| **OEE** | التوقفات والكفاءة | تسجيل التوقفات بسبب (يدوي أو من الماكينة)، Availability × Performance × Quality حسب ISO 22400، Six Big Losses، Pareto | Kernel |
| **LBL** | الباركود والملصقات | تصميم قوالب، طباعة ZPL/EPL مباشرة على طابعات Zebra/TSC، GS1-128 و DataMatrix، إعادة طباعة بصلاحية | Kernel |
| **LBR** | العمال والمهارات | تسجيل حضور على الخط، مهارات وشهادات، منع العامل غير المؤهل من محطة، ساعات عمل لكل أمر | Kernel |
| **TOOL** | الأدوات والقوالب | سجل قوالب/أدوات، عدد الطلقات/الاستخدام، حد عمر وتنبيه، ربط قالب بمنتج، تركيب/فك على ماكينة | Kernel (+OEE اختياري) |
| **CMMS** | الصيانة | صيانة وقائية (زمنية/بالعداد)، أوامر صيانة للأعطال، قطع غيار، MTBF / MTTR | Kernel (+OEE) |
| **APS** | الجدولة | خطة إنتاج، جدولة على الخطوط بسعة محدودة، Gantt بالسحب والإفلات، تغيير المنتج (changeover)، مقارنة المخطط بالفعلي | Kernel |
| **ALM** | التنبيهات والتصعيد | قواعد (لو X حصل → بلّغ Y بعد Z دقيقة)، أندون، تصعيد متدرج، إشعار على الشاشة/إيميل/SMS/تليجرام لاحقًا | Kernel |
| **DSH** | الشاشات اللحظية | لوحات الخط (Andon board) للتليفزيون، لوحة المصنع، مخطط مقابل فعلي بالساعة | Kernel |
| **RPT** | التقارير | تقارير جاهزة (إنتاج يومي، فاقد، توقفات، جودة، تتبع) + مصمم تقارير بسيط + جدولة إرسال | Kernel |
| **EDGE** | اتصال الماكينات | Gateway منفصل: OPC UA، MQTT/Sparkplug B، Modbus، I/O؛ عدادات تلقائية وحالات تشغيل | OEE |
| **ERP** | التكامل | REST API موثق، Webhooks، موصلات جاهزة (ERPNext, Odoo, SAP B1)، B2MML | Kernel |
| **INV** | مخزن الخامات الخفيف | استلام، مواقع، صرف للخط بالمسح، FIFO/FEFO، رصيد (مش بديل ERP) | Kernel |
| **DOC** | تعليمات العمل | PDF/صور/فيديو لكل خطوة، إصدارات، إقرار العامل بالقراءة | Kernel |

### باقات مقترحة للبيع (تجميعات جاهزة من الوحدات)
| الباقة | الوحدات | لمين |
|---|---|---|
| **Start** | Kernel + WIP + LBL + RPT + DSH | مصنع عايز يعرف "إحنا فين" |
| **Quality** | Start + QMS + TRC | مورد لشركات سيارات/أجهزة/غذاء، عنده تدقيق عملاء |
| **Performance** | Start + OEE + ALM + CMMS + TOOL | مصنع بلاستيك/حقن/مكابس همه الكفاءة |
| **Full** | كل الوحدات | — |

## 2.3 مصفوفة التغطية مقابل ISA-95 Part 3

| نشاط ISA-95 | الإنتاج | الجودة | الصيانة | المخزون |
|---|---|---|---|---|
| Definition management | MDM (BOM, Routing) | QMS (Inspection plans) | CMMS (PM plans) | MDM (Items) |
| Resource management | MDM, LBR, TOOL | QMS (gauges لاحقًا) | CMMS (spares) | INV |
| Detailed scheduling | APS | QMS (sampling) | CMMS (PM calendar) | INV |
| Dispatching | EXE (Release) | QMS (inspection tasks) | CMMS (work orders) | INV (issue to line) |
| Execution management | EXE | QMS (hold/release) | CMMS | INV/WIP |
| Data collection | EXE, EDGE, OEE | QMS, SPC | CMMS, EDGE | TRC |
| Tracking | WIP, TRC | QMS (NCR) | CMMS (history) | TRC |
| Performance analysis | OEE, RPT, DSH | SPC, RPT | CMMS (MTBF) | RPT |
